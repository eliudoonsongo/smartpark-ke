# smartpark-ke

A modern parking dashboard that automatically displays parking slot status and core parking operations.

## Features

- Live slot board with automatic status refresh
- Slot statistics (total, available, occupied, reserved, maintenance)
- Park vehicle by plate number into the next available slot
- Release occupied slots
- Quick filter by slot status

## Run

Open `/home/runner/work/smartpark-ke/smartpark-ke/index.html` in a browser.

## Files

- `index.html` - UI structure
- `styles.css` - dashboard styling
- `app.js` - parking state, rendering, and interactions
